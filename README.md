Personal customizations on top of [end-4/dots-hyprland](https://github.com/end-4/dots-hyprland). This is not a fork: it only contains the files I changed or added, so it won't work on its own. Requires the original setup to be installed first.

## Why is Quickshell not included?

My Quickshell setup is the stock end-4/dots-hyprland shell with no plugins and only a few tiny tweaks, so there is nothing worth publishing beyond what upstream already provides. To avoid redistributing someone else's code unnecessarily, I left it out. If you want the same shell, install it from the original repository: [end-4/dots-hyprland](https://github.com/end-4/dots-hyprland).
